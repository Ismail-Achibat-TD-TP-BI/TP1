Smart Internship Match

A personal decision-support dashboard for an internship search: real postings, matched against my own skills, tracked through to outcomes.

Provenance and known limits of this run:
  • Source: Jooble (an officially issued API key), not France Travail — the "Offres d'emploi v2" scope was never granted on this course's francetravail.io application (a real token request returned invalid_client).
  • Jooble returns a short, pre-truncated snippet (~300 chars), not the full posting text — expect weaker skill extraction than a full-text source would give.
  • Matching score = 60% coverage of the offer's stated skills + 40% my own self-assessed level (1-5) on the skills I matched — a deliberate two-factor construct, not a neutral count. See REPORT.md for the full argument.
  • A generic word like "informatique" sometimes shows up as a "skill gap" below — a real, observed extraction error (the model occasionally extracts the domain name itself as if it were a skill), not a genuine thing to learn.

Match-score distribution (histogram → bar chart)

The decision this supports is "is my search producing real candidates, or mostly noise?" — a histogram is the standard chart for seeing a distribution's shape at a glance, which a table of 30 individual scores wouldn't show as clearly.

What's most in demand that I'm missing vs. already strong in (ranked bars)

Two rankings, not one: "what to learn next" (gaps) and "what to lead with" (matched strengths) are different, actionable questions — a ranked bar is the right type for both, same reasoning as every other "ranking → bar chart" in this course, because each bar is one specific thing I could actually act on.
